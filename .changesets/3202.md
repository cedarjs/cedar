- feat(cli): expire tenancy invitations (#3202) by @Tobbe

`yarn cedar setup tenancy` now generates `invitationExpiresAt DateTime?` on
`Membership`. `inviteMember` sets it seven days out and returns it on
`Invitation`, and `claimInvitation` refuses an invitation past its expiry, both
for `acceptInvitation` and for signing up with a token.

Apps that already ran `setup tenancy` are not changed. To get the column, add
`invitationExpiresAt DateTime?` to `Membership` in `api/db/schema.prisma` and
run `yarn cedar prisma migrate dev`. Pending invitations without an expiry
(`null`) never expire, so existing invitations keep working. To expire them, set
`invitationExpiresAt` on those rows. The generated `organizations.ts`,
`organizations.sdl.ts` and tests are yours to edit. To get the behaviour, copy
both halves from the new templates: `inviteMember` setting
`invitationExpiresAt` (otherwise new invitations never expire either) and the
expiry condition in `claimInvitation`'s guard. Add `invitationExpiresAt` to the
SDL's `Invitation` type if you want to show the date.
