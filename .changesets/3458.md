- fix(internal): The API build rewrites the `src/` alias in dynamic imports,
  side-effect imports and `require()` by @rj-au (#3458)

`applySrcAlias` rewrites `src/` specifiers to relative paths in every import
form that `applyImportExtensions` handles: static imports and re-exports,
side-effect imports (`import 'src/lib/setup'`), dynamic imports
(`await import('src/lib/db')`) and `require('src/lib/db')` calls. A dynamic
import of `src/…` in `api/src` resolves at runtime in the built API.

Template-literal specifiers (``import(`src/lib/${name}`)``) are not rewritten.
