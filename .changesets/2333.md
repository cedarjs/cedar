- fix(cli): quote Windows shell args for background processes (#2333) by
  @simoncrypta

Telemetry and update-check spawn a detached Node process with `shell: true` on
Windows. Unquoted paths that contain spaces (CI's `test project` directory, or a
user path like `C:\Users\First Last\...`) split into extra argv tokens, so Node
loads a truncated module path and throws `MODULE_NOT_FOUND`.

`spawnBackgroundProcess` now quotes each argument using CommandLineToArgvW
backslash rules before concatenating the command line.
