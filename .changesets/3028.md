- feat(jobs): pause and resume declared schedules (#3028) by @Tobbe

A declared schedule can be paused and resumed while the app runs, without a code
change or a deploy, for example to stop a nightly job during an incident:

```bash
yarn cedar jobs pause ReportJob:nightly
yarn cedar jobs resume ReportJob:nightly
yarn cedar jobs schedules
```

The same is available in code as `jobs.pauseSchedule(ReportJob, 'nightly')`,
`jobs.resumeSchedule(ReportJob, 'nightly')` and `jobs.listSchedules()`. Workers
don't pick up a paused schedule. A run in progress finishes, and the pause holds
across worker restarts and schedule syncs. A resumed schedule runs next at the
next match of its cron; runs missed while it was paused are not made up for.
Every worker logs a warning listing the paused schedules when it starts.

Pausing needs a new column on the `BackgroundJob` model. Add
`pausedAt DateTime?` to it and run `yarn cedar prisma migrate dev`. Apps without
the column keep working as before; pausing a schedule throws until the column is
there.
