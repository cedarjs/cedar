- fix(auth): Replace the stub requireAuth test when setting up auth by @Tobbe

`yarn cedar setup auth <provider>` updates
`api/src/directives/requireAuth/requireAuth.test.{ts,js}` to match the real
`requireAuth` implementation. It tests that the directive throws without a
current user and passes with one, so the api test suite passes right after
setting up auth.

The test is only updated if it still contains the unmodified test case that new
apps ship with, and only when setup writes `api/src/lib/auth.{ts,js}`.
Customized tests, and tests for a kept `requireAuth` (for example when you
decline overwriting existing files), are left as they are.
