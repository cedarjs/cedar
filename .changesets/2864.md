- fix(uploads): Request a fresh upload token when the current one is spent or
  expired by @Tobbe

`useFsUpload` and `useS3Upload` keep track of how many files the current upload
token has been used for and when it expires, and fetch a fresh token when it
has no files left or is about to expire. A mounted upload component can upload
any number of times, including with a `maxFiles: 1` profile.
