- feat(codegen): make SDL-only fields optional when a field resolver provides them (#3256) by @Tobbe

A field that's in the SDL but not on the Prisma model, and that a field resolver
on the type computes (`export const Organization = { smsSenderDefault: … }` in a
service), is optional on the generated resolver result types. Services that
return the Prisma row type-check when annotated with
`QueryResolvers['myOrganization']`, as long as each computed field has a field
resolver. SDL-only fields without a field resolver are still required. Fields
that are also on the Prisma model keep their Prisma types.
