- fix(codegen): Read Prisma model names from a TypeScript prisma-client (#2445)
  by @ladderschool

If your `schema.prisma` uses Prisma's `prisma-client` generator with a
TypeScript output — which is the default in Prisma 7 — GraphQL codegen could not
read your model names, because Node cannot `import()` a `.ts` file.

```prisma
generator client {
  provider               = "prisma-client"
  output                 = "../src/lib/prisma"
  generatedFileExtension = "ts"
}
```

The symptom was a `api/types/graphql.d.ts` generated with no Prisma models
mapped in: the `import { … } from 'src/lib/db'` line came out empty,
`AllMappedModels` was empty, and SDL types lost the fields they should have
inherited through `MergePrismaWithSdlTypes`. Codegen also shelled out to
`cedar prisma generate` on every run trying to recover.

Codegen now reads `Prisma.ModelName` directly out of the generated
`internal/prismaNamespace.<ext>` file when the client is TypeScript. JavaScript
clients are unchanged.
