- fix(jobs): Stop importing all of type-fest for the priority type by @Tobbe

The type for a job's `priority` option is defined inside `@cedarjs/jobs`, so
`type-fest` is not a dependency of the package. Apps that type-check with
`skipLibCheck: false` don't load type-fest's declaration files through
`@cedarjs/jobs`, which makes `yarn cedar type-check` noticeably faster on the
api side.

`priority` still accepts only the integers 1 to 100, and your editor still flags
values outside that range.
