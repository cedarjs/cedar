- fix(cli-helpers): Remove barrel export file by @lisa-assistant

`packages/cli-helpers/src/index.ts` was a barrel export file re-exporting
everything from the package's submodules, already flagged with an `@WARN`
comment about the memory problems this causes in the CLI: every consumer that
imports anything from `@cedarjs/cli-helpers` pulled in the entire package graph
(all 10+ submodules), regardless of what it actually used.

`@cedarjs/cli-helpers` now exposes only its existing subpath exports
(`@cedarjs/cli-helpers/colors`, `@cedarjs/cli-helpers/paths`,
`@cedarjs/cli-helpers/project`, `@cedarjs/cli-helpers/telemetry`, etc.) — the
root `@cedarjs/cli-helpers` entry point no longer exists.

This is only a breaking change for anyone deep-importing directly from
`@cedarjs/cli-helpers` outside of the monorepo (it's not a Cedar app dependency,
so this doesn't affect end-user Cedar apps). All in-repo consumers (the CLI,
auth-provider setup packages, codemods, create-cedar-app) have been migrated to
the subpath imports already.
