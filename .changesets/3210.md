- feat(uploads): say why a content type is rejected (#3210) by @Tobbe

When `POST /upload/fs` refuses a file because of its content type, the error
now names the type the client sent and the type the bytes are, and which type
to add to `allowedMimeTypes`. For example, an iPhone photo sent as `image/heic`
whose bytes are `image/heic-sequence`. The new `checkContentType()` returns the
same verdict as `acceptedContentType()` with the reason: `{ contentType }` or
`{ rejected: { detected, claimed } }`.
