- feat(dbauth)!: Add a changePassword flow for logged in users by @Tobbe

dbAuth has a change password flow for users who are already logged in. They
enter their current password along with the new one, so someone who only has
access to a logged in session can't use it to take over the account. The forgot
password and reset password flows remain the way back in for users who don't
know their password.

- `DbAuthHandler` requires a `changePassword` option, like the `login`,
  `signup`, `forgotPassword` and `resetPassword` options. It takes a `handler`,
  an `allowReusedPassword` setting and custom `errors`, or `{ enabled: false }`
  to turn the flow off.
- `useAuth()` returns `changePassword({ currentPassword, newPassword })`.
- `yarn cedar generate dbAuth` creates a `ChangePasswordPage` at
  `/change-password`. Pass `--skip-change` to leave it out.
- `yarn cedar setup auth dbAuth` adds `changePasswordOptions` to
  `api/src/functions/auth`.

**Breaking:** existing TypeScript auth functions fail type-check until they
pass a `changePassword` option. Add `changePassword: { enabled: false }` to keep
the flow off, or see the
[dbAuth docs](https://cedarjs.com/docs/auth/dbauth#changepassword) to turn it
on. `yarn cedar upgrade` lists the files that need it and prints the code to
add. JavaScript auth functions without the option keep working, with the flow
turned off.
