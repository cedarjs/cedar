- fix(tenancy): setup tenancy leaves a clean app, and runs again (#3173) by @Tobbe

After `yarn cedar setup tenancy`, the app type-checks, lints and passes its
tests, and running setup again changes nothing:

- The next steps include `yarn cedar prisma generate`, which Prisma 7's
  `migrate dev` no longer runs, before `data-migrate up`.
- The generated organizations tests and scenarios fill every field your
  `User` model requires, not just dbAuth's.
- Every file setup writes or changes is formatted and lint-fixed with your
  app's own config.
- A second run recognizes everything the first one did, keeps template files
  that are already there (unless `--force`), and doesn't add the data
  migration twice.

`mockCurrentUser()` and `mockRedwoodDirective`'s `context` now take a partial
user: a mocked user only needs the fields your test uses.
