- feat(mailer): Add an AhaSend mail handler (#2844) by @Tobbe

`@cedarjs/mailer-handler-ahasend` sends email through
[AhaSend](https://ahasend.com/), an EU-based transactional email provider.
Configure it with your AhaSend API key and account ID:

```ts
ahasend: new AhaSendMailHandler({
  apiKey: process.env.AHASEND_API_KEY,
  accountId: process.env.AHASEND_ACCOUNT_ID,
}),
```

Each email is sent as one message that all `to`, `cc` and `bcc` recipients
share. Failed requests are retried with an idempotency key, so a retry of a
request AhaSend already accepted does not queue the email again. When AhaSend
accepts some recipients and rejects others, for example suppressed addresses,
`mailer.send()` resolves and the
result for each recipient is available in `handlerInformation`. It rejects when
no recipient is accepted. See the
[AhaSend handler docs](https://cedarjs.com/docs/mailer/ahasend) for setup and
options.
