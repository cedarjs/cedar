- fix(cli): Send an unchanged scaffold DateTime field back as stored (#2798) by @Tobbe

The edit form that `yarn cedar g scaffold` generates for a model with a
`DateTime` field sends the field's stored value back when the field is saved
without being changed. A `datetime-local` input only holds minutes, so this
keeps the stored seconds and milliseconds, and it keeps the right hour when
daylight saving time ends and the same local hour occurs twice. A field that
is edited or cleared is sent as entered.

Only newly generated forms get this. To update a form that was generated
earlier, regenerate it.
