- fix(tenancy): type $forOrg clients like db (#3209) by @Tobbe

`db.$forOrg(id)` has the same type as `db`, so a helper can take a `typeof db`
parameter and be passed either. `db.$withoutTenant()` has `db`'s models and
`$transaction` and types raw SQL as allowed; its type is exported as
`UnscopedClient`. Both clients have `$forOrg` and `$withoutTenant` themselves.
