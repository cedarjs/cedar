- fix(cli): Pin @cedarjs/testing to the project's Cedar version in generated
  packages by @Tobbe

`yarn cedar generate package` used to add `"@cedarjs/testing": "2.2.1"` to the
new package's `devDependencies`, no matter which version of Cedar the project
was on. It now uses the same version as the Cedar CLI you run it with, so a
package generated in a v7 project gets `@cedarjs/testing` 7.x.

Packages you've already generated keep their old pin. To update one, change
`@cedarjs/testing` in its `package.json` to your project's Cedar version and
run `yarn install`.
