- fix(cli): remove `fullName` from `setup tenancy` test/scenario templates
  by @lisa-assistant

`yarn cedar setup tenancy` generates `organizations.scenarios.ts` and
`organizations.test.ts` with fixture users that set a `fullName` field. That
field isn't part of the `User` model `yarn cedar setup auth dbAuth
--createUserModel` creates, so a fresh dbAuth app that then runs `setup
tenancy` fails both `cedar type-check` (`fullName` doesn't exist on
`UserCreateInput`) and `cedar test api` (Prisma rejects the unknown
`fullName` argument).

Removed `fullName: '...'` from every fixture user in
`packages/cli/src/commands/setup/tenancy/templates/organizations.scenarios.ts.template`
and `organizations.test.ts.template`, matching the templates' own stated
assumption of a plain dbAuth-style `User` model (`email`, `hashedPassword`,
`salt`).
