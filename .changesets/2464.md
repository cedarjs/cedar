- fix(codegen): Read Prisma model names from the generated models file (#2464)
  by @ladderschool

GraphQL codegen imported the whole generated Prisma client just to read
`Prisma.ModelName` — the only thing it takes from the client. On one production
app that was 4.5 MB of generated TypeScript plus the @prisma/client runtime, to
learn 38 strings.

Reading a single file is both faster and uses less memory than importing the
entire client. Since the client was imported with a cache busting name, node
would import a new client each time the code was executed, leading to a slow
memory leak.
