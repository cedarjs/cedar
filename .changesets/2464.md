- feat(codegen): Read Prisma model names from the generated models file (#2464) by @ladderschool

GraphQL codegen imported the whole generated Prisma client just to read
`Prisma.ModelName` — the only thing it takes from the client. On one production
app that was 4.5 MB of generated TypeScript plus the `@prisma/client` runtime,
to learn 38 strings. Because the import used a cache-busting query string, Node
would load a fresh copy of that client on every codegen run, leaking memory
over time.

Codegen now reads the model names straight out of the `models.<ext>` barrel
file Prisma writes next to the client, for every `generatedFileExtension`
instead of importing the client at all. That's faster, uses less memory, and
stops the leak.
