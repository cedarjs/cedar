- fix(internal): Type mockGraphQLQuery and vitest globals in web tests by @Tobbe

`mockGraphQLQuery` and `mockGraphQLMutation` are now typed in web test files,
and `vi` is typed in both web and api test files, so `yarn cedar type-check`
accepts them without imports or local type shims. If your app has its own
`.d.ts` shim that declares these globals, delete it to avoid duplicate
declaration errors.
