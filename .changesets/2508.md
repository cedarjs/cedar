- fix(dbAuth): Support SimpleWebAuthn v13 (#2508) by @ladderschool

`DbAuthHandler` was calling SimpleWebAuthn with the API that v11 renamed, so
dbAuth's WebAuthn flows stopped working on any project past v10. Registration
called `create()` with `id: undefined` and Prisma rejected it; authentication
threw on an undefined `credential`. Both surfaced as a 400, and since the
`webAuthn` cookie is set after a successful registration or a verified
authentication, `WebAuthnClient.isEnabled()` never returned true either.

Projects using `@simplewebauthn/server@^10`, `^11`, or `^12` need to upgrade
to:

- `@simplewebauthn/server@13.3.3`
- `@simplewebauthn/browser@13.3.0`

And remove the dependency

- `@simplewebauthn/types` — v11 folded those types back into
  `@simplewebauthn/server`

`@cedarjs/auth-dbauth-api` now declares `@simplewebauthn/server@^13.0.0` as an
optional peer dependency. It is optional because projects that never ran
`setup auth dbAuth --webauthn` do not install the library. Projects that do
enable WebAuthn need a compatible `@simplewebauthn/server@^13.0.0`, since
`DbAuthHandler.webAuthnRegister()` and `DbAuthHandler.webAuthnAuthenticate()`
dynamically import it at runtime.
