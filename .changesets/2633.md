- fix(eslint-config): disable `react/react-in-jsx-scope` by @niukanen1

Cedar apps compile JSX with the automatic runtime, so React is never in scope
by design. The shared preset enabled `react/react-in-jsx-scope`, which flagged
every JSX file that doesn't `import React` — one error per file, on freshly
scaffolded apps. The preset now enables eslint-plugin-react's `jsx-runtime`
config (turning off `react/react-in-jsx-scope` and `react/jsx-uses-react`),
the same pattern the framework's own root ESLint config uses.
