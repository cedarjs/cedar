- fix(tenancy): allow raw SQL in unscoped transactions (#3211) by @Tobbe

In `db.$withoutTenant().$transaction(async (tx) => ...)`, `tx` allows raw SQL
again, as it does at runtime, so e.g. a transaction-scoped advisory lock with
`tx.$queryRaw` type-checks. `tx` otherwise has the type of `db`'s own
transaction client, and the batch form, `$transaction([...])`, is unchanged.
