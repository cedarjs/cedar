- feat(web): Declare Apollo Client's cache type as InMemoryCache (#2750) by
  @Tobbe

`CedarApolloProvider` always creates the client's cache with Apollo's
`InMemoryCache`, and `@cedarjs/web` now tells Apollo Client so through its
`TypeOverrides` interface. `client.cache`, `useApolloClient().cache`,
`useCache().cache` and the `cache` argument of mutation `update` callbacks are
typed as `InMemoryCache` instead of the abstract `ApolloCache`, so app code can
use `InMemoryCache`-specific APIs without casting.

The declaration is shipped with `@cedarjs/web`, which means a project can't
declare a different `cache` type in Apollo's `TypeOverrides` itself. Passing
your own cache via `graphQLClientConfig.cache` still works, but it has to be an
`InMemoryCache`.
