- fix(dbAuth): Reject unverified WebAuthn assertions in `webAuthnAuthenticate` (#2545) by @Tobbe

`DbAuthHandler.webAuthnAuthenticate()` throws a `WebAuthnError` and issues no
cookies when `verifyAuthenticationResponse()` resolves `{ verified: false }`.
`SimpleWebAuthn` throws for most failure modes, but a signature that doesn't
match the stored public key comes back this way instead, with no exception — so
checking `verified` explicitly, before doing anything else, is what keeps a
forged or mismatched signature from resulting in a valid session for the
credential's owner. This mirrors how `webAuthnRegister()` already checks its own
`verified` result.

The only information an attacker needs to reach this path is a credential ID for
the victim, and credential IDs are not secret in the WebAuthn model — so this
check is the actual gate on the login, not a formality.
