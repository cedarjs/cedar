- fix(cli): Show scaffold DateTime fields in the local timezone (#2794) by @Tobbe

The `formatDatetime` helper that `yarn cedar g scaffold` adds to forms with a
`DateTime` field gives the form's `datetime-local` input the timestamp in the
user's local time. The input's value is read back as local time when the form
is submitted, so saving an edit form without changing the field keeps the
stored time. In any timezone other than UTC, the form showed the UTC digits
instead, and every save moved the stored time by the user's UTC offset.

Only newly generated forms get the new helper. To fix a form that was
generated earlier, regenerate it or replace its `formatDatetime` function with
the one from a new scaffold.
