- fix(cli): Show scaffold DateTime fields in the local timezone (#2794) by @Tobbe

The `formatDatetime` helper that `yarn cedar g scaffold` adds to forms with a
`DateTime` field converts the API's UTC timestamp to the user's local time for
the form's `datetime-local` input. The input's value is read back as local time
when the form is submitted, so saving an edit form without changing the field
keeps the stored time. The one exception is the hour that repeats when daylight
saving time ends: a `datetime-local` input has no offset, so it can't tell the
two occurrences of that hour apart and the second one is stored as the first.

Only newly generated forms get the new helper. To update a form that was
generated earlier, regenerate it or replace its `formatDatetime` function with
the one from a new scaffold.
