- feat(uploads): optional built-in sharp generator for derived files
  (experimental) (#3064) by @Tobbe

`sharpVariant()` from `@cedarjs/uploads/sharp` makes image thumbnails and
resizes for derived files: `sharpVariant({ width: 164 })` is a 164 × 164 WebP
cropped from the middle, and `height`, `fit: 'inside'`, `format` (`webp`,
`jpeg`, `png`, `avif`) and `quality` cover the rest. Images are turned the right
way up by their EXIF orientation and written without metadata. Only JPEG, PNG,
WebP, GIF, AVIF and TIFF files are decoded, told apart by their bytes.

`sharp` is an optional peer dependency: install it with
`yarn workspace api add sharp` to use the generator. Without it, or when sharp
can't load its native library, `sharpVariant()` throws when your app starts,
saying how to fix it.

The generator runs sharp in your API process. For images from untrusted sources,
the uploads docs show a generator that runs sharp in `@cedarjs/api/sandbox`
instead.
