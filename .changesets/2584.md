- fix(api): Upgrade Pino to v10 by @lisa-assistant

`@cedarjs/api`'s logger and `@cedarjs/api-server`'s test suite were pinned to
Pino v9, which sits well behind the latest v10.3.1 release. Renovate flags
major bumps for manual approval, so this one had been sitting unapplied since
Pino v10 stabilized.

Pino v10's only breaking change is dropping support for Node.js 18, which
Cedar already doesn't support (`packages/api`'s `engines` field requires
`>=24`). `pino-abstract-transport` is bumped alongside it to v3.0.0
(previously v1.2.0 in `@cedarjs/api-server`'s devDependencies), whose only
breaking change is the same Node 18 drop.

No source changes were needed: `packages/api/src/logger/index.ts` and
`packages/api-server`'s test usage both use standard, unaffected Pino APIs
(`pino(options, stream)`, `logger.info/warn/error/debug`, and the abstract
transport's `build()` helper).

`pino` isn't a peer dependency of any Cedar package, so no action is needed
in Cedar apps.
