- fix(jobs): Accept PrismaAdapter in the Adapters type by @Tobbe

The `api/src/lib/jobs.ts` file generated by `yarn cedar setup jobs` type-checks.
`PrismaAdapter`, and any custom adapter extending `BaseAdapter`, can be passed
to `JobManager`'s `adapters`, whatever its `schedule()` method returns.

The scheduler returned by `jobs.createScheduler()` returns the adapter's own
`schedule()` return type, so `await later(MyJob)` is typed as `PrismaJob` when
using the Prisma adapter.
