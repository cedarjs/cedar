- feat(deploy): Netlify skew protection — deploy-ID stamping + manifest by @lisa-assistant

Adds `cedarNetlifySkewProtectionPlugin`, wired into `cedar setup deploy netlify
--ud`. During the client build it writes `.netlify/v1/skew-protection.json`
(Netlify's [Frameworks API](https://docs.netlify.com/build/frameworks/frameworks-api/#netlifyv1skew-protectionjson)
build output for skew protection), registering `cedar-skew-token` as both
header and cookie name, and `skew` as the query param name.

It also stamps the current deploy's `NETLIFY_SKEW_PROTECTION_TOKEN` into the
SSR bundle via a `virtual:cedar-netlify-skew-token` module, since Cedar's
universal-deploy Fetchable entries don't have Netlify's runtime `context`
forwarded through and so can't read `context.deploy.skewProtectionToken`
directly.

This PR covers deploy-ID stamping and manifest generation only. Runtime
cookie/header propagation (setting the token on first response, attaching it
to subsequent requests so clients stay pinned to their deploy) is scoped to a
follow-up PR. Baremetal deploy support is a separate follow-up once Netlify
support ships.
