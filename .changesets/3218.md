- fix(create-cedar-app): type-check test globals with `vitest/globals`, not
  `@types/jest` (#3218) by @lisa-assistant

New TypeScript projects' `api/tsconfig.json` and `web/tsconfig.json` set
`"types": ["vitest/globals"]` instead of `"types": ["jest"]` (and `"jest-dom"`
on the web side). Cedar's test runner is Vitest, and `vitest/globals` is
Vitest's own ambient types for `describe`, `it`, `test`, `expect`, `vi`, etc.
`@types/jest`'s declarations happened to work as an unintended type-only shim,
but under pnpm it isn't hoisted to where the app's `typeRoots` look for it, so
`tsc` failed with `TS2688: Cannot find type definition file for 'jest'`. The
`jest-dom` entry relied on an unrelated `typeRoots` trick to pull in
`@testing-library/jest-dom`'s Jest-flavored type augmentation; its Vitest
matchers are already added automatically by the
`@testing-library/jest-dom/vitest` import in the generated `vitest.setup.ts`.
