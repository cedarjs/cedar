- fix(jobs): Schedule a cron job's first run from its cron expression by @Tobbe

Recurring jobs scheduled with `later(job, args, { cron })` have their first run
at the next time the cron expression matches, the same way the job is
rescheduled after each successful run. Registering a recurring job, for example
from a script at deploy time, doesn't run it right away.

An invalid cron expression throws when the job is scheduled.
