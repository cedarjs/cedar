- feat(cells): support <CellName>Fragment<Prop> fragment names (#3248) by @Tobbe

A fragment Cell's fragment can be named `<CellName>Fragment`, like `AuthorCellFragment`, which gives a data prop named after the fragment's type (`on User` → `user`). Adding a PascalCased name, like `PostCellFragmentAuthor` in `PostCell`, gives that name as the prop (`author`). Unlike `AuthorCell_author`, these names don't trigger the `camelcase` lint rule when you import the generated fragment type. Fragment names with an underscore keep working as before. `yarn cedar g cell <name> --fragment <Type>` generates `<Name>CellFragment`.
