- fix(cli): Make the scaffold date helpers typed function declarations (#2786) by @Tobbe

The `formatDatetime` helper that `yarn cedar g scaffold` adds to forms with a
`DateTime` field is a typed function declaration with a JSDoc comment. It takes
`string | null | undefined` and returns `string | undefined`, matching the
generated GraphQL types and what `DatetimeLocalField`'s `defaultValue` accepts.

`timeTag` in the generated `web/src/lib/formatters.tsx` is a function
declaration too.

Neither helper's runtime behavior is different, and existing scaffolds are not
affected. Only newly generated files get the new form.
