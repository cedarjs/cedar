- feat(cli): integrate @cedarjs/pg for local Postgres in dev and test (#2283) by
  @simoncrypta

Opt into worktree-isolated local Postgres with `@cedarjs/pg` (alpha) + autopg:

```bash
# New apps
yarn create cedar-app --esm --db cedar-pg my-app

# Existing apps
yarn cedar setup cedar-pg
```

Set `CEDAR_PG=1` (setup does this). Then `yarn cedar dev` / `yarn cedar test`
provision a per-worktree database and inject `DATABASE_URL`. Dev DBs persist
across restarts; test DBs are disposed when the suite finishes.

Override with an explicit `DATABASE_URL` / `TEST_DATABASE_URL` (skips acquire
unless `CEDAR_PG_FORCE=1`). See
[Local Postgres Setup](https://cedarjs.com/docs/local-postgres-setup).
